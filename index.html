    Start

    Mit Windows starten (lauscht im Hintergrund)
    Im Vollbild öffnen
    Im Schlaf Fenster schließen (spart ~800 MB)

    ORB wartet unsichtbar mit ~30 MB. Zweimal klatschen → ORB springt im Vollbild an. Ist „Jarvis“ an, wird das Fenster im Schlaf nur ausgeblendet, damit ORB dich weiter hört.
